## 2026-05-15
- Lesson: Scene Director does NOT enforce house style. The user handles style at generation time. Scene prompts contain only WHAT is on screen, never HOW it's drawn. No color, no medium, no line weight, no animation cues.
- Trigger: User feedback — "I will take care of the style separately."

## 2026-05-15
- Lesson: Recurring characters must have a canonical description that is RE-stated in every scene's prompt that features them. Image generators have no memory across prompts. Maintain a "Character library" section at the top of each episode's `05-scenes.md` and paste the canonical description into each scene's prompt verbatim.
- Trigger: User feedback — "if there is a character that is repeated a few times, this character should have its own description that should be added separately to each prompt. Since the AI does not know that we have a character, it should, in each prompt, be described the same as it was described before."

## 2026-05-15
- Lesson: One scene can include two places or events if the narration flows that way. Keep the narration flow over the "one subject per scene" rule.
- Trigger: User feedback — "it's okay to have two different events in one scene, but what's important is to keep the flow."

## 2026-05-15
- Lesson: Output format is narration FIRST, then prompt BELOW. Each scene block: voice-over text on top, image prompt underneath. So every line of narration has a clearly-paired visual.
- Trigger: User feedback — "Make sure each text is written first, and then written below it the prompt, so each text in the voice-over will have its equivalent image or scene."

## 2026-05-15
- Lesson: No animation. The channel works by drawing each scene on a whiteboard, holding it, going to the next. Each scene is one still drawing — no motion, no transitions described.
- Trigger: User feedback — "There will be no animation, no nothing, just scenes being drawn."
