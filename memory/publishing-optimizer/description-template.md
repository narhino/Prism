# Description template

Every prizm video description follows this structure. The Publishing Optimizer fills in the variables.

## Structure

```
[HOOK LINE — one sentence summary of the thesis. Must be honest about
what the video delivers. This is what the viewer sees before clicking
"show more". Max 200 characters.]

[BLANK LINE]

[SETUP PARAGRAPH — 3-4 sentences. Name the news trigger, the
mechanism, and the central beneficiary. Include at least two specific
numbers.]

[BLANK LINE]

⏱ CHAPTERS
0:00 — [Beat 1 title]
0:30 — [Beat 2 title]
1:00 — [Beat 3 title]
3:00 — [Beat 4 title]
9:00 — [Beat 5 title]

[BLANK LINE]

📓 SOURCES
- [Outlet — Headline — URL]
- [Outlet — Headline — URL]
- [...]

[BLANK LINE]

🔍 ABOUT prizm
Every headline is a transaction. We show you who's on the other side.
New episodes weekly.

[BLANK LINE]

#prizm #[topic-tag-1] #[topic-tag-2] #[topic-tag-3]
```

## Rules
- **Hook line**: ≤200 characters. Visible without clicking "show more". Must match the video's actual thesis — no clickbait the script doesn't deliver.
- **Setup paragraph**: name the news trigger, the mechanism, and the central beneficiary. Two specific numbers minimum.
- **Chapters**: must match the actual `[BEAT: ...]` markers and timestamps from `04-script.md`. Beat titles can be reframed for browsability (e.g. "Cold open" → "Monday morning, the strait closed").
- **Sources**: 3–7 real, verifiable, original-reporting sources from `01-news.md`. No paywalled-only links if a free alternative exists.
- **Channel blurb**: stays consistent across all videos. Use the brand bible's one-liner verbatim.
- **Hashtags**: 3–5 max. First one always `#prizm`.
- **No emojis** in the body text — only as section markers (⏱ 📓 🔍).
- **No CTAs** — no "🔔 SUBSCRIBE", no "👍 LIKE", no "let me know in the comments".
- **No claims the script doesn't deliver.**
