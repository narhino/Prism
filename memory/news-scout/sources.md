# News sources

**Operating rule (locked 2026-05-15):** News Scout pulls news *live* via web search on every `/pull-news` invocation. The user does not pre-curate headlines. Never rely on cached recall or training data — always fetch fresh.

Pull from this list first. Update as the user adds or removes sources.

## Primary (original reporting)
- Reuters
- Financial Times (FT)
- Bloomberg
- Wall Street Journal (WSJ)
- Associated Press (AP)
- The Economist
- Axios
- Semafor

## Secondary / niche
- "Money Stuff" by Matt Levine (Bloomberg newsletter) — best single source for fraud, finance plumbing, weird incentives
- The Information (tech)
- Sherwood News
- Restoration Hardware / Odd Lots (Bloomberg podcast leads)

## Flagged sources (use carefully)
- ZeroHedge — biased toward doom narratives. Useful for spotting what conspiracy-leaning audiences are reacting to, not for primary facts.

## Notes
- News sources change. Update this list when the user brings new ones.
- For paywalled stories, check whether another outlet has covered the same news.
